## Что отправить боту

Можно начать с номера телефона, почты, ника или полного имени. Для поиска по имени полезно добавить город или дату рождения, если они известны. Если у вас есть только страница в МАКС, сохраните её точную ссылку и посмотрите, какой username указан в профиле.

Бот ищет по известным параметрам в доступных ему записях. В них могут встретиться старые имена, другие аккаунты или контактные данные. Состав результата зависит от найденных записей. Посмотрите, какие поля появились по вашему запросу.

Сравните несколько деталей. Старый номер мог перейти другому человеку, а ник мог поменяться. Если найденная запись датирована несколькими годами раньше, воспринимайте её как историческую. Совпадение по одному имени лучше проверить по ссылке, дате или другому известному признаку.
